# CA LazySetup

Fusion 360 add-in that prepares 2D/CNC milling setups: silhouette contours, tabs/bridges, roughing & finishing passes, tool selection, live plan preview.

**Version:** 2.0.9 · **License:** MIT · Author: Chris Adam / Chris Adam Modellbau

## Features
- Dual-pass workflow (roughing + finishing) with separate direction and tab options
- Bridge/tab editing in the palette preview
- Presets, multi-language UI (DE/EN/ES/FR)
- Shared CA Tools shell (theme, diagnostics, donate info)

## Install
See [docs/QUICKSTART_EN.md](docs/QUICKSTART_EN.md) or run `INSTALL.bat` / `install.ps1` (Fusion closed). Target folder:

`%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazySetup`

User files (`user_settings.json`, `user_presets.json`, `logs/`) are kept.
