# CA LazySetup

Fusion-360-Add-in zur Fräsvorbereitung: Silhouetten, Stege, Vor-/Fertigfräsen, Werkzeugwahl, Planvorschau.

**Version:** 2.0.10 · **Lizenz:** MIT · Autor: Chris Adam / Chris Adam Modellbau

## Funktionen
- Doppel-Schnitt (Vorfräsen + Fertigfräsen) mit eigener Richtung/Stegen
- Stege in der Vorschau editieren
- Presets, UI DE/EN/ES/FR
- Gemeinsame CA-Tools-Infobox (Theme, Diagnose, Spende)

## Installation
Siehe [docs/QUICKSTART_DE.md](docs/QUICKSTART_DE.md) oder `INSTALL.bat` / `install.ps1` (Fusion zu). Ziel:

`%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazySetup`

Nutzerdaten bleiben erhalten.
