# Quick start – CA LazySetup

## Requirements
- Autodesk Fusion (Windows recommended)
- This repo / ZIP extracted

## Install
1. **Quit** Fusion.
2. Double-click `INSTALL.bat` (or run `install.ps1` in PowerShell).
3. Start Fusion → **Utilities → Add-Ins → Scripts and Add-Ins**.
4. Select **LazySetup** → **Run** / enable Run on Startup.

Manual path: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazySetup`

## First steps
1. Open a design with parts/sheets.
2. Open the **CA LazySetup** palette.
3. Pick a tool; check roughing/finishing options.
4. **Update preview**, then apply / run.
5. ⓘ = info, diagnostics, donate.
