# Démarrage rapide – CA LazySetup

## Prérequis
- Autodesk Fusion (Windows recommandé)
- Repo / ZIP extrait

## Installation
1. **Fermer** Fusion.
2. Double-cliquer `INSTALL.bat` (ou lancer `install.ps1`).
3. Ouvrir Fusion → **Utilitaires → Modules complémentaires**.
4. Sélectionner **LazySetup** → **Exécuter** / démarrage auto.

Chemin : `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazySetup`

## Premiers pas
1. Ouvrir un design avec pièces/feuilles.
2. Ouvrir la palette **CA LazySetup**.
3. Choisir l’outil ; vérifier ébauche/finition.
4. **Actualiser l’aperçu**, puis appliquer / lancer.
5. ⓘ = info, diagnostic, don.
