# Kurzanleitung – CA LazySetup

## Voraussetzungen
- Autodesk Fusion (Windows empfohlen)
- Dieses Repo / ZIP entpackt

## Installation
1. Fusion **schließen**.
2. `INSTALL.bat` doppelklicken (oder `install.ps1` in PowerShell).
3. Fusion starten → **Dienstprogramme → Add-Ins → Scripts und Add-Ins**.
4. **LazySetup** markieren → **Ausführen** / automatisch starten aktivieren.

Pfad manuell: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazySetup`

## Erste Schritte
1. Design mit Bauteilen/Blättern öffnen.
2. Palette **CA LazySetup** öffnen.
3. Werkzeug wählen, Vorfräsen/Fertigfräsen-Parameter prüfen.
4. **Vorschau aktualisieren**, dann **Übernehmen** / Lauf starten.
5. ⓘ = Info, Diagnose, Spendenhinweis.
