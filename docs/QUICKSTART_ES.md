# Guía rápida – CA LazySetup

## Requisitos
- Autodesk Fusion (Windows recomendado)
- Repo / ZIP descomprimido

## Instalación
1. **Cerrar** Fusion.
2. Doble clic en `INSTALL.bat` (o ejecutar `install.ps1`).
3. Abrir Fusion → **Utilidades → Complementos → Scripts y complementos**.
4. Seleccionar **LazySetup** → **Ejecutar** / inicio automático.

Ruta: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\LazySetup`

## Primeros pasos
1. Abrir un diseño con piezas/láminas.
2. Abrir la paleta **CA LazySetup**.
3. Elegir herramienta; revisar desbaste/acabado.
4. **Actualizar vista previa**, luego aplicar / ejecutar.
5. ⓘ = info, diagnóstico, donación.
